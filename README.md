\# Personal Budget Tracker



\## Description



A simple web-based personal budget and expense tracker created with HTML and CSS.



\## Features



\- Add expense form

\- Expense category dropdown

\- Expense table with sample expenses

\- Alternating table rows

\- Table row hover effects

\- Budgeting tips section

\- Interactive details section

\- Budgeting video using YouTube iframe

\- Budget tracker image

\- Responsive styling



\## Technologies Used



\- HTML5

\- CSS3



\## Project Files



\- `index.html` — Main webpage structure

\- `style.css` — Page styling and advanced CSS selectors

\- `README.md` — Project documentation



\## How to Run



Open `index.html` in a web browser, or use VS Code Live Server.
